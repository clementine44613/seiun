# Contributing to Seiun Auth

Thank you for your interest in improving this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch (git checkout -b feature/my-change).
3. Make your changes.
4. Verify the bot starts without errors (
pm start).
5. Commit with a clear message.
6. Push and open a Pull Request.

## Code style

- JavaScript: follow the existing style in src/ and index.js.
- Java: follow the existing style in mc-mod/src/.
- Do not modify .env or indings.json; these are runtime files.

## Reporting bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Relevant log output (index.js console logs or MC latest.log)
